# Tug - NestJS Backend Application

A NestJS backend application built with TypeScript.

## Description

This is a NestJS backend application with TypeScript support, ready for development.

## Installation

```bash
npm install
```

## Running the app

```bash
# development
npm run start

# watch mode
npm run start:dev

# production mode
npm run start:prod
```

## Test

```bash
# unit tests
npm test

# e2e tests
npm run test:e2e

# test coverage
npm run test:cov
```

## API Endpoints

- `GET /` - Returns "Hello World!"

## Development

The application runs on `http://localhost:3000` by default.
